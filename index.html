🔌 IoT Circuit Wiring Reference (Copeland Dixell XR06CX RS485 ➔ ESP32)
1. Dixell Port Terminal 9 (Data A) → MAX485 Board Pin A
2. Dixell Port Terminal 10 (Data B) → MAX485 Board Pin B
3. MAX485 RO Pin → ESP32 GPIO 16 (RX2)  |  MAX485 DI Pin → ESP32 GPIO 17 (TX2)
4. MAX485 DE & RE Pins → ESP32 GPIO 4 (RTS Control Pin)
5. Telemetry Protocol: ESP32 sends HTTP POST JSON payload to https://sahashrajanith.site/api/telemetry.php every 5 seconds.
